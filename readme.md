# Allen James — AJ Edits Portfolio Website

A responsive single-page portfolio for Allen James Pepito, focused on video editing and motion graphics. It includes selected work, an About section based on Allen’s CV, a selected-experience timeline, primary tools, services, and contact links.

## Preview locally

1. Unzip the package if you downloaded the ZIP.
2. Open `index.html` in a modern browser.
3. The Work section shows one card per category. Categories with several projects open as a folder; a category with a single project opens that project's sample directly. The first project listed in each category is used as its thumbnail.
